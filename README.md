# Adult Zone

A private library for the videos you own. Windows 10/11, 64-bit. Adults only.

**[Download](../../releases/latest)** · Setup.exe or portable zip

## Features

- Reads your existing folders; nothing moved or renamed
- Scenes and movies
- Looping previews
- Plays anything
- Performer and studio pages
- Find info, one video or the whole library
- Your own home screen rows
- PIN lock
- Updates itself
