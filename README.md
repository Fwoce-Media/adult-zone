# adult-zone

A self-hosted media library for video files you already have on your own
machine.

Point it at a folder and it builds a browsable library from what it finds —
artwork, titles, resume points and watch history — served over your local
network to whatever device you want to watch on. Nothing is downloaded,
streamed in, or uploaded anywhere; it only ever reads the files you give it.

## Why it exists

Local video collections are awkward to browse from a sofa. A file manager is
not a viewing experience, and most media servers are heavier than a single
person needs. This is a light one.

## What it does

- Scans a folder and builds a library from the files in it
- Remembers where you stopped and lets you resume
- Serves to phones, tablets and browsers on the same network
- Runs entirely on your own hardware

## Notes

Built for personal use and shared as-is. There is no hosted version, no
account system, and no content of any kind included — it is a player for
files you supply.
